ABOUT THE MIRROR

一份写给时间看的
官微档案

微信公众号的内容会随时间沉入信息流底部。这个镜像站把华南农业大学官方微信号的公开推文整理成可检索、可回看的网页，并始终保留通往原文的链接。

01

自动同步

GitHub Actions 定时运行，不依赖任何一台常开电脑，也不会从你的本地网络发起抓取。

02

双源正文

先读取学校官方澎湃号的完整正文，再尝试增强为微信原文全文；失败时自动回退，不让文章缺席。

03

原文可溯

每篇文章都保留微信原文与官方澎湃号链接。内容版权归华南农业大学，本站仅作公开信息的非营利归档。
